Apa itu PaaS?

Platform untuk membangun, menjalankan, dan menerbitkan aplikasi.

Platform as a Service (PaaS) adalah layanan cloud yang menyediakan lingkungan untuk mengembangkan dan menjalankan aplikasi. Pengguna berfokus pada kode aplikasi, sedangkan penyedia platform menangani banyak kebutuhan infrastruktur dan runtime.

🚀 Deployment lebih praktis

Aplikasi dapat diterbitkan melalui repository kode dan pengaturan build.

🛠️ Tidak mengelola server fisik

Pengguna tidak perlu menyiapkan perangkat keras server sendiri.

🌐 Akses melalui URL

Aplikasi yang berhasil diterbitkan dapat diakses melalui alamat web.

🔄 Pembaruan aplikasi

Kode dapat diperbarui dan di-deploy kembali ketika diperlukan.

🧪

Langkah Praktikum

Alur sederhana untuk menerbitkan aplikasi web menggunakan Render.

1

Buat repository

Siapkan repository GitHub dan masukkan file aplikasi serta file dependensi.

2

Hubungkan Render

Buat Web Service baru dan pilih repository yang berisi aplikasi.

3

Deploy & uji

Tunggu deployment selesai, buka URL Render, lalu pastikan halaman dapat diakses.

Catatan: Render merupakan platform PaaS untuk praktik ini. Ketersediaan paket gratis dan batas penggunaannya mengikuti kebijakan Render yang berlaku.
